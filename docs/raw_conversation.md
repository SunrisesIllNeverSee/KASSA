Let me lay it out honestly.

The Howey Test. Since 1946, the SEC determines whether something is a security using four criteria. ALL four must be met:

An investment of money — Yes. Buyers pay real money for seats. This prong is always met.
In a common enterprise — This is where it gets interesting. A "common enterprise" means the buyers' fortunes are tied to the fortunes of the promoter or to each other. If you buy a COMMAND seat, is your financial outcome tied to what Luthen does with the money? If the answer is "the product gets better and my seat appreciates because of the founder's work" — that starts to look common. If the answer is "I bought access to a tool I use, and if I stop using it I can sell the position" — that looks like a purchase with resale rights.
With an expectation of profits — This is the critical prong. If buyers purchase seats BECAUSE they expect the seat to appreciate and they can sell it for more later, that's an expectation of profits. If buyers purchase seats to USE the product and the transfer feature is a convenience, not the motivation — that's not an expectation of profits. The distinction is: are people buying to use, or buying to flip?
Derived from the efforts of others — If the seat's value increases because the FOUNDER builds the product, improves it, markets it — that's value derived from someone else's efforts. If the seat's value is static (lifetime access at a fixed utility level), this prong weakens.
